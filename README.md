# 🌶️ Spice Route Kitchen

> Premium mobile-first restaurant website — React + Vite

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build for Production

```bash
npm run build
npm run preview
```

## Project Structure

```
src/
├── assets/        # Images, icons, fonts
├── components/    # Reusable UI components
├── constants/     # All app data & config
├── context/       # React Context (Theme, Auth)
├── hooks/         # Custom hooks
├── layouts/       # MainLayout, AuthLayout
├── pages/         # Home, About, Dashboard
├── routes/        # AppRoutes.jsx
├── services/      # API calls
├── store/         # Zustand store
└── utils/         # Helper functions
```

## Tech Stack
- React 18 + Vite
- React Router v6
- Zustand (state)
- Google Fonts (Cormorant Garamond + DM Sans)
